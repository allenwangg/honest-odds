Every option price is a probability in disguise.

By Breeden–Litzenberger, the slope of call prices across strikes is the market's own probability that the underlying finishes above that strike. So a live options chain is a prediction market, quoting odds on hundreds of events all day, priced by people with money at stake. Almost nobody reads it that way.

Pythia reads it that way. Each cycle it pulls near-dated chains for SPY, QQQ, NVDA, TSLA and COIN through Alpaca's options data API and rebuilds that probability curve from live quotes — no-arbitrage cleanup, stale and one-sided quotes rejected, put–call parity used as a lie detector. It hands the curve to Claude as a calibrated forecaster whose prior is the market's number, and trades only where the two disagree by enough, as a defined-risk debit spread whose maximum loss is known to the dollar before the order leaves.

The scoring

Every forecast is written down before it resolves, and graded after.

Not just the ones that became trades — the skipped and gate-blocked ones too, so the brain is scored even when the hands were tied. The rule is Brier: mean squared error of a probability against a 0/1 outcome. It is proper, meaning the only way to minimise it is to report what you actually believe. Hedging toward 50% is penalised; so is bluster.

The benchmark isn't a naive baseline. It's the chain itself — the same quotes the forecast was read from.

The pipeline then grid-searches the shrinkage λ in p = (1−λ)·p_model + λ·p_market that would have scored best, and feeds it back into config. This week the answer was λ = 0.00 — no amount of deference to the market improved the score. That is a measurement, not a preference.

Buying a put spread is a bearish disagreement. So the trade filter fires precisely on the one subset where the model scored worse than the market it was arguing with.

Pythia produced four losing forecasts all week. Three of them are the three it traded.

The honest caveats, since a proper scoring rule is only worth publishing if it can embarrass you: n=37 over four sessions is small; ten strikes on one underlying for one expiry resolve on a single draw, so the effective sample is nearer eight than thirty-seven; and 65% of scored strikes closed above their level in a week that trended up, which flatters a forecaster who was systematically more bullish and more confident. Sixteen bearish observations is not yet enough to justify patching the config, which is why the finding is logged rather than acted on.

The loss came in $44 inside the cap the gate printed before the order was sent, which is the entire point of the gate. The position was closed at 11:14 the next morning rather than held to expiry, because a long put settling in-the-money auto-exercises into short shares — unbounded overnight risk on an options-only mandate, the night before a payrolls print.

It is in the journal with the reasoning that produced it. A forecaster who only publishes the calls that land is not a forecaster.

What stands between a plan and the exchange

Eight gates with no ML and no LLM inside them.

The intelligence upstream can be wrong — that is what a probabilistic forecast means. These cannot be argued with. Limits are parameters; the gates are not.

G1
Defined risk
Net-debit structures only. Bounded max loss, no naked shorts.

Per-trade budget
Hard cap on the loss any single position may carry.

Positions are managed by rule too. A take-profit rule closed SPY puts at +193% and TSLA puts at +101% on the same morning, with no human involved and no model consulted.

Alpaca, twice

One brokerage account, two interfaces, each doing what it is best at.

Execution — Trading API

Atomic multi-leg MLEG limit orders at net debit. Deterministic pythia- client order ids, so a restart cannot double-enter. Auto-retry on price-increment rejects, and a --flatten that closes everything and cancels the rest. The loop needs determinism, not judgment.

Supervision — official MCP server

Alpaca's own MCP server, connected to the same account, is how a human interrogates and overrides the agent in plain English: "close the QQQ put spread — I disagree with today's thesis." The human needs language, not an order ticket. Setup that actually works is in mcp/README.md.

The loop never asks the model for permission. The human never places an order by hand. Every decision — traded, skipped, gate-blocked, banked — lands in the journal with its thesis, and Claude writes a nightly fund letter from it.
